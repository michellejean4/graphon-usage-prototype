# Graphon usage and upgrade components

The pieces used in the usage and upgrade prototype. They follow shadcn/ui conventions and Tailwind v4, so they slot into Graphon's existing app.

Use the toolbar at the top to switch between **light and dark** mode and between the three **usage** states (plenty left, getting close, out of queries).

## Install with the shadcn CLI

<pre><code>{`npx shadcn@latest add https://graphon-usage-prototype.vercel.app/r/graphon-theme.json
npx shadcn@latest add https://graphon-usage-prototype.vercel.app/r/meter.json
npx shadcn@latest add https://graphon-usage-prototype.vercel.app/r/button.json`}</code></pre>

Badge, card, switch and dialog are available the same way.

## Rules

- Blue means upgrade. It is only used for things you can click to upgrade.
- Meters are solid in light mode and fade from a rich colour to a deep one in dark mode.
- Meters turn red only at 100%. Members never turn red, a full team is normal.
- The usage banner can be dismissed in every state. It returns when the usage state changes.

## Standard vs added

- **From shadcn:** button, badge, card, dialog, switch. The button adds an `upgrade` variant and uses GitHub's sizes.
- **Added:** meter, usage banner, upgrade dialog, bar chart. The last three are feature pieces and show the intended states; they are wired to demo data in the prototype.
